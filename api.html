Dokumentasi API

Integrasikan mesin ekstraksi video TikTok dan transkripsi AI ke dalam aplikasi Anda.

POST /api/process

Menerima tautan TikTok, mengunduh video tanpa watermark, serta menghasilkan transkripsi audio otomatis menggunakan model AI Faster-Whisper.

Request Body (JSON)

  • url string (required) — Tautan video TikTok yang valid (misal: https://vt.tiktok.com/...). 
{
  "url": "https://vt.tiktok.com/ZSxxxxxx/"
}

Response (200 OK)

{
  "status": "success",
  "download_url": "/api/download/video_a1b2c3d4.mp4",
  "filename": "TickText_@username.mp4",
  "transcript": [
    {
      "start": 0.0,
      "end": 2.5,
      "text": "Halo semuanya, selamat datang kembali!"
    },
    {
      "start": 2.5,
      "end": 5.1,
      "text": "Hari ini kita bakal bahas topik menarik..."
    }
  ]
}
GET /api/download/{filename}

Mengunduh file video MP4 yang telah berhasil diproses oleh server.

Path Parameters

  • filename string (required) — Nama file internal yang didapat dari respons download_url.

Ketentuan & Batasan API

  • • Maximum File Size: 200 MB
  • • File TTL (Time-to-Live): 5 Menit (file akan dihapus otomatis dari server).
  • • CORS Enabled: Bebas diakses dari origin domain mana pun.

Kami tidak berafiliasi dengan TikTok, Douyin, atau Bytedance.
